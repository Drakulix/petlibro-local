# Adding a Translation

1. Copy `en.json` to a new file named with the ISO 639-1 language code (e.g. `fr.json` for French, `de.json` for German).
2. Translate every value. Keep all keys exactly as-is -- only change the values.
3. Open a pull request. The language will appear automatically in the Settings tab once the file is deployed.

Keys use dot notation: `section.subsection.key`. Placeholders like `{count}` are substituted at runtime -- leave them in place.

Thank you for contributing!
